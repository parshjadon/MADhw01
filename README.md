# Calculator Studio

Flutter calculator app for CSC 6370 Assignment 01.

## Implemented requirements

- Number input from 0 through 9.
- Addition, subtraction, multiplication, and division.
- Readable result display with responsive layout.
- Stateful two-operand calculator flow.
- Graduate requirements implemented:
  - Decimal input and decimal arithmetic across all four operations.
  - Calculation history with tap-to-reuse and clear history.
  - Advanced operations: percent, square root, and sign toggle.
  - Backspace/delete with long-press clear behavior.

## Run and test

```powershell
flutter pub get
flutter run
flutter analyze
flutter test
flutter build apk
```

The release APK is generated at:

```text
build/app/outputs/flutter-apk/app-release.apk
```
